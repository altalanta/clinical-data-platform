# Clinical Data Platform

## Build Mode: NEW_REPO

### Why it exists
A self-contained dbt + DuckDB clinical analytics sandbox that walks from raw synthetic EHR extracts to survival-ready feature marts with deterministic tests, docs, and CI.

```
+-----------+     +-----------+     +-----------------+     +--------------------+
| Raw CSVs | --> | Staging   | --> | Intermediate     | --> | Marts & Survival   |
| (data/)  |     | (models/) |     | (feature joins) |     | (dim/fact/exposure)|
+-----------+     +-----------+     +-----------------+     +--------------------+
```

### Quickstart (three commands to green)
```
make env
make dbt-init
make all
```
> Need to reuse an existing interpreter (e.g., offline environments)? Prefix commands with `SKIP_ENV=1` to skip virtualenv creation.

### Repo tour
| Path | Description |
| ---- | ----------- |
| `scripts/` | Deterministic data generation + validation guardrails |
| `data/raw/` | Synthetic source CSVs generated by `gen_synth_data.py` |
| `data/seeds/` | ICD→CCS and LOINC category mappings (seeded via dbt) |
| `models/staging/` | Raw ingests with casting, key normalization, and tests |
| `models/intermediate/` | Index logic, lookback windows, lab aggregation, comorbidity flags |
| `models/marts/` | Cohort, feature, and survival outputs with exposure definition |
| `analyses/` | Cohort and model cards for downstream consumers |
| `ci/workflow.yml` | GitHub Actions pipeline wiring `make all` + artifacts |

### Model lineage snapshot
| Layer | Key models | Purpose |
| ----- | ---------- | ------- |
| Staging | `stg_patients`, `stg_encounters`, `stg_labs` | Typed records sourced from synthetic CSVs |
| Intermediate | `int_index_dates`, `int_lab_latest`, `int_dx_flags`, `int_proc_flags` | Derive index date, lookback windows, lab flags, and feature pivots |
| Marts | `dim_patient`, `fct_cohort`, `fct_features`, `survival/mart_survival_features` | Cohort eligibility, engineered features, survival labels + exposure |

### Cohort logic
- Age ≥ 18 on the derived index date (first INPT encounter or high-risk diagnosis).
- ≥1 encounter in the 365-day lookback window and ≤120 days since latest pre-index visit.
- No additional exclusions; deterministic synthetic population retains all adults meeting activity requirements.

### Determinism contract
- Synthetic data generator seeded via `--seed 1337` (see `make data`).
- dbt seeds and models pinned through `requirements.txt` + `.deps-installed` stamp.
- Guardrail assertions live in `scripts/validate_metrics.py` and run locally + in CI.

### Performance profile
- Designed for laptops: `make all` finishes in <5 minutes and <2 GB RAM on an Apple M1.
- DuckDB keeps execution in-process—no external services or warehouses required.
